# Hotel Stone

Site do **Hotel Stone**, desenvolvido como uma aplicação web responsiva e PWA.

## Tecnologias

* React
* TypeScript
* Vite
* React Router
* Vite PWA
* CSS

## Funcionalidades

* Página inicial do hotel
* Seção "Sobre nós"
* Listagem de quartos
* Página de detalhes dos quartos
* Navegação entre páginas
* Layout responsivo
* Aplicação instalável como PWA
* Funcionamento offline

## Como executar

Clone o repositório e instale as dependências:

```bash
npm install
```

Execute o projeto em desenvolvimento:

```bash
npm run dev
```

Para gerar a versão de produção:

```bash
npm run build
```

Para testar a versão de produção:

```bash
npm run preview
```

## PWA

O projeto possui **Manifest** e **Service Worker** configurados com `vite-plugin-pwa`, permitindo a instalação da aplicação e seu funcionamento offline após o carregamento dos recursos.
